# more_malloc_free

Projet Holberton : encore plus de malloc et free en C.

## Fichiers
- 0-malloc_checked.c : réserve de la mémoire, quitte avec le code 98 si malloc échoue
- 1-string_nconcat.c : concatène s1 et les n premiers octets de s2
- 2-calloc.c : réserve un tableau et le met à zéro
- 3-array_range.c : crée un tableau d'entiers de min à max
