# Function pointers

Learning how to use pointers to functions in C.

## Files

- `function_pointers.h`: prototypes for tasks 0 to 2
- `0-print_name.c`: prints a name using a function passed as parameter
- `1-array_iterator.c`: executes a function on each element of an array
- `2-int_index.c`: searches for an integer using a comparison function
- `3-calc.h`, `3-op_functions.c`, `3-get_op_func.c`, `3-main.c`: simple calculator using an array of function pointers
