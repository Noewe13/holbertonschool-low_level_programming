# structures_typedef

Projet Holberton sur les structures et typedef en C.

## Fichiers
- dog.h : définit struct dog, le type dog_t et les prototypes
- 1-init_dog.c : initialise une variable de type struct dog
- 2-print_dog.c : affiche une struct dog
- 4-new_dog.c : crée un nouveau chien
- 5-free_dog.c : libère un chien
