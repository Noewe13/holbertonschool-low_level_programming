# malloc_free

Projet Holberton sur l'allocation dynamique de mémoire en C avec malloc et free.

## Fichiers
- 0-create_array.c : crée un tableau de chars rempli avec un caractère
- 1-strdup.c : copie une chaîne dans une nouvelle zone mémoire
- 2-str_concat.c : concatène deux chaînes
- 3-alloc_grid.c : crée une grille 2D d'entiers initialisés à 0
- 4-free_grid.c : libère une grille 2D
