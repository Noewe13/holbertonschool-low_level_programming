# C - Variadic functions

Functions that take a variable number of arguments, using
`va_start`, `va_arg` and `va_end` from `<stdarg.h>`.

| File | Description |
|------|-------------|
| `variadic_functions.h` | Header with all prototypes |
| `0-sum_them_all.c` | Returns the sum of all its parameters |
| `1-print_numbers.c` | Prints numbers with a separator |
| `2-print_strings.c` | Prints strings with a separator, `(nil)` if NULL |
| `3-print_all.c` | Prints chars, ints, floats and strings |
